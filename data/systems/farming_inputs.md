# Farming — Inputs

**Status: stub.** 1%-knowledge topic Pedro is donating.

## Scope

What you **feed** your maps to amplify their content density. The inputs:

- **Waystones** — base map currency (see `waystones`)
- **Precursor Tablets** — atlas-region content modifiers (see `atlas_towers_and_tablets`)
- **Scarabs / fragments** (per current patch) — specific mechanic amplifiers
- **Omens** — applied to specific encounter types within maps
- **Sextants / equivalents** (per current patch) — atlas-wide modifiers
- **Specific currencies for league mechanics** — Bones for Abyssal crafting, Runeshapes for Ezomyte work

Sub-topics to be expanded:
- The input budget per map: how much currency to invest before EV inverts
- Input-stacking patterns (waystone × tablet × omen for mechanic compound)
- Input-pricing: which inputs are cheap-and-effective vs expensive-and-mandatory
- Sourcing inputs from previous maps vs buying from market
- The bait input — "fancy" inputs that don't actually amplify output
- League-phase pricing on inputs (early-league cheap omens, late-league expensive omens)
- Bulk-input strategies (buy 100 of one tablet, run for a phase)

The 1% practice is **explicit budgeting per map**, not feel-based input addition.
