# Crafting — Gear (Body Armour, Helm, Gloves, Boots)

**Status: stub.** 1%-knowledge topic Pedro is donating.

## Scope

Crafting the four core armour slots. Each slot has **distinct leverage** — what scales best on chest doesn't scale best on gloves.

Sub-topics to be expanded:

**Chest (Body Armour)** — the spirit + ehp slot:
- Spirit modifier as the primary scaling lever for many builds
- The chest-ehp vs chest-spirit decision
- Sockets on chest (max 2) — what to socket
- Hybrid defense bases (armour+ES, evasion+ES, armour+evasion+ES)
- Pinnacle uniques + the craft-vs-buy decision for body armour

**Helm** — the aura-effect + specific-support slot:
- Aura effect modifiers and which auras they amplify
- Specific support modifiers (helms with "Socketed Skills are Supported by X")
- Strict ehp helms vs effect-modifier helms

**Gloves** — the action-speed slot:
- Attack speed / cast speed as the primary scaling
- Trigger / culling / on-hit modifiers
- The "specific gloves for specific skills" pattern

**Boots** — the movement + filler slot:
- Movement speed as a default-required modifier
- Ehp fillers (life, resists, ES)
- Onslaught / specific buffs on boots
- Specific unique boots that change the gameplay loop

The **slot-leverage discipline** — knowing which slot to invest currency in first per build — is the 1% practice this guide will expand.
