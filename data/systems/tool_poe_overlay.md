# POE Overlay (tool guide)

**Status: stub.** General-purpose PoE overlay — stash, character, items, atlas.

## Scope

Multi-purpose in-game overlay. Older than Awakened PoE Trade; broader feature set; less focused. Some players prefer it for the stash-tab quick-view and atlas-overview features that Awakened doesn't provide.

Sub-topics to be expanded:
- Feature overlap with Awakened PoE Trade (price-check is in both; trade-engaged players typically prefer Awakened)
- Features unique to POE Overlay (stash quick-view, atlas overlay)
- When to install BOTH POE Overlay + Awakened (rare — most players pick one)
- PoE 2 support status (active maintenance unclear; verify before installing)

## Install

Official source: search "POE Overlay" on GitHub. Standalone exe.

## How poe2-graph reads it

Filesystem scanner detects (probe `poe_overlay`) → `trade_overlay_user` tag.
