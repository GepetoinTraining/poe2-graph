# Soul Cores (PoE 2)

Powerful socketable items. Fit the same gear sockets as runes but with **wider, rarer modifier pools** unavailable to regular runes.

## What makes a Soul Core different from a rune

- **Wider modifier pool** — Spirit bonuses, Item Rarity modifiers, and other modifiers that runes can't roll.
- **Higher magnitude** on basic stats — when a Soul Core grants elemental damage or resistance, it's usually larger than the rune equivalent.
- **Rarer source** — only drops from the **Trial of Chaos** (see `trials_of_chaos`).
- **Same socket footprint** — fits in the same socket slots as runes; uses the same Artificer Orb mechanism for socket creation.

## Where Soul Cores come from

**Trial of Chaos exclusively**. Specifically:

- **Round 4 boss** — guaranteed Soul Core drop
- **Round 7 boss** — guaranteed Soul Core drop
- **Round 10 boss** — guaranteed Soul Core drop + Fate (for Trialmaster challenge)
- Additional Soul Core drops are possible from non-boss rounds at higher difficulties

So: each cleared Trial of Chaos run gives 3+ Soul Cores. Quantity scales with difficulty cleared.

## The permanent-commitment rule

**Soul Cores cannot be removed once socketed.**

This is the critical constraint. Once you slot a Soul Core into an item, the Soul Core is bound to that item permanently. You can replace it with another Soul Core or Rune — but the original Soul Core is destroyed in the process (same as the rune replacement rule).

**Practical implication**: never Soul Core into mid-tier gear that you'll replace. Save them for **your endgame keepers** — gear you intend to use for the rest of the league.

## Common Soul Core types

(Modifier categories — specific Soul Core names vary patch to patch.)

| Modifier category | Why it matters |
|---|---|
| **+Spirit** | High-magnitude spirit on a socketable; aura/buff capacity |
| **+Item Rarity** | Endgame farming amplification |
| **Elemental damage to attacks** | Damage scaling beyond rune-tier |
| **Resistances at higher magnitudes** | Cap resists in fewer slots |
| **Movement speed** | Rare modifier source on socketables |
| **Boss-specific stats** | (Various) — niche but high-impact |

## Strategic socketing — when to use Soul Cores

Decision tree:

1. **Is the item I'm socketing into a permanent keeper?** If no, use runes instead. Save Soul Cores.
2. **Is the Soul Core's modifier something I genuinely need?** If you're already capped on resists and the Soul Core rolls resists, the modifier is wasted.
3. **Is this the best slot for this Soul Core?** A +Spirit Soul Core on body armour adds spirit on top of already-large body-armour spirit; the same Soul Core on gloves might be more leverage if body armour is your spirit ceiling.

## Trialmaster + Soul Cores

The **Trialmaster** fight (accessed via Fates from difficulty-4 round-10 Trial of Chaos) drops **exclusive Soul Cores** not available elsewhere — top-tier endgame socketables. If you're committed to engaging Trial of Chaos at difficulty 4, the Trialmaster is the natural progression.

## Common mistakes

- **Socketing Soul Cores into upgrade-tier gear** — wasted Soul Cores when you replace the item.
- **Replacing Soul Cores frequently** — every replacement destroys the previous one. Plan once.
- **Treating Soul Cores like a generic upgrade** — sometimes a well-rolled rune is comparable to a low-tier Soul Core. Read both.
- **Ignoring Soul Cores for clearing builds** — speedclear / mapping builds benefit massively from Item Rarity Soul Cores, which mostly drop ONLY from Soul Cores (rarely from runes).
